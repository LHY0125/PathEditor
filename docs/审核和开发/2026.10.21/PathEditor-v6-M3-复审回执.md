### 3.2 R-1：为什么没有采用方案 A

审查报告推荐 **A（整包拒绝）**。我没有采用，理由如下——请复核这个判断：

**A 的实际代价**：`save_profile_tx` 会为每次配置保存记录 `profile` + `profile_revision` 两条变更。
因此**任何存过配置的用户**，其同步包必然包含这两类。若 A 生效，
该用户的**整包**（含本可同步的 PATH 快照）都会被拒绝——同步对所有用过配置的人不可用。

**我采用的 B'**：

1. 新增 `APPLICABLE_ENTITY_TYPES = &["snapshot"]`，与白名单 `KNOWN_ENTITY_TYPES` **分开**。
   前者决定「能不能落地」，后者决定「包是否合法」。R-1 的成因正是把两者混为一谈。
2. 不支持的类型：**不应用、不计数进 `applied`、单独计入 `skipped_unsupported`**。
3. **并且不写 `changes`**——这是审查报告未提到的第二层陷阱：
   一旦写了，uid 就被占住，将来真正支持该类型时同一个包会因「uid 已存在」被**永久跳过**。
   用户会得到一条永远无法补齐的同步记录。
4. UI/CLI 显式显示这个数字，见 3.3。

**B' 相对 A 的可逆性**：若审核窗口仍坚持 A，改动只有一处——把
`report.skipped_unsupported += 1; continue;` 换成 `return Err(SyncFormat)`。
我把两种语义的差别压到了一行。

**连带影响（报告未提及，我主动记录）**：
`profile` 类型的变更现在根本不进入 LWW 比较，因此**冲突只在快照上产生**。
这与「配置本来就不落库」一致，但它是行为变化，已同步改掉冲突测试的实体类型
（由 `profile` 改为 `snapshot`），并在测试注释里写明原因。

### 3.3 F-4：改成「store 不产出文案」而不是「store 调 `t()`」

审查报告建议把文案换成 i18n。我做得更彻底一些：

- store 的 `notice` 从 `string` 改为**结构化联合类型** `SyncNotice`：
  `{kind:'exported'|'imported'|'resolved', ...}`。
- 文案由 `SyncCenter` 的 `renderNotice()` 经 `t()` 渲染。

**为什么不让 store 调 `i18n.t()`**：store 是状态层，产出面向用户的句子属于展示职责。
把 `t()` 塞进 store 只是把「中文」换成「运行时语言的字符串」，分层问题仍在。
结构化后，**主反馈（导入/导出/解决的结果提示）不再由 store 产出中文**，
切换语言不需要改这几条文案。

**但 store 里仍有中文字符串**：`errorMessage` 的三条兜底
（`同步不可用（降级模式）` / `同步包无效` / `同步操作失败`）与
`maskConflictValue` 的空值占位 `(空)`。这部分属于**错误码本地化**，
本轮未动，归 M4（审查报告同判：建议连同错误码本地化一起处理）。

> **自我更正**：本回执初版此句写作「store 里一个中文字符都没有」，**与事实不符**，
> 由审查窗口指出。已按上述更正——主反馈确实迁移正确，但「整个 store 无中文」是夸大。

新增三条 i18n 键（中英各一份）：`noticeExported` / `noticeImported` / `noticeImportedUnsupported`。
`noticeImportedUnsupported` **只在 `skippedUnsupported > 0` 时**使用，
把「这 N 条没同步」明确说出来。

### 3.4 白名单测试

新增 `core/tests/db_sync_import_limits.rs`（一文件一测试），覆盖两段：

1. **含 1 条快照 + 1 条配置的包** → `applied == 1`、`skipped_unsupported == 1`，
   且 `changes` 表里 `entity_type='profile'` 的行数**为 0**（守第二层陷阱）。
   再导入同一包：`applied == 0`、`skipped == 1`、`skipped_unsupported == 1`（幂等口径）。
2. **未知 `entityType = "backups"`** → `SyncFormat`，文案含「未知的实体类型」，
   且导入前后 `changes` 行数**不变**（整包回滚）。
